Every report arrives as a page like this one. This copy doubles as the component gallery: each element below is what the build script produces from ordinary markdown.

Recommendation

Bottom line

Write markdown, run the build script, open the page. The script turns a normal agent report into this layout: contents on the left, the answer up top, risks and decisions called out, evidence folded away until you want it.

Recommendation

A paragraph that opens with a bold label such as Recommendation: or Smallest version worth having: becomes this box, together with the list that follows it.

Main risks

  • A label containing "risk", "caveat" or "concern" becomes a risk box.
  • The list under the label comes along with it.

Decision needed

Labels like Decision needed: or Open question: become this box. A report that needs several rulings links to its ruling page from here.

1.Verified and inferred

Agents tag claims with Verified or Inferred. A source after the tag stays beside it Verifieddocs.github.com, so the reader can see what each claim rests on at a glance.1

Verified

A blockquote starting [!VERIFIED] becomes this box.

Inferred

And [!INFERRED] becomes this one.

Tables

Tables with four or more rows sort by clicking a column heading. On a phone each row becomes a card with its column names beside the values.
