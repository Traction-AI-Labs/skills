# The hand-off plan for the support desk

Date: 2026-11-10. A sample report for the page states. The front matter at the top is what changes between the live, reference, replaced and partly replaced copies.

## Bottom line

**The support desk can start on Monday if the shared inbox is set up by Friday.** Two things still need a decision, and one depends on the weekend roster.

## 1. What changes for customers

Customers keep writing to the same address. Replies are signed with a first name, and every email gets an answer within one working day.

| What | Today | From Monday |
|---|---|---|
| Where emails land | Five inboxes | One shared inbox |
| Reply time | Up to a week | One working day |
| Weekend | Nobody | Nobody |
| Signature | None | First name |

## 2. Who does what

Ana runs the inbox in the mornings and Ben in the afternoons. Anything about refunds goes to Cleo.

**Main risks:**
- The shared inbox is not set up by Friday.
- Refund questions pile up while Cleo is away.

## 3. The roster

A two-week roster, starting Monday. Swaps go through Ana.
